VeyAmux

Capture-card viewer and video player for Linux with GPU upscaling, frame generation, HDR, recording and streaming.

Install

Install with your software centre

Or in a terminal: add the repository once, then install. Updates come with flatpak update or through Discover / GNOME Software.

flatpak remote-add --user --if-not-exists veyamux @BASE@/veyamux.flatpakrepo
flatpak install --user veyamux io.github._8BiTw0LF.VeyAmux

The KDE runtime VeyAmux needs comes from Flathub. For Lossless Scaling frame generation, also install the lsfg-vk extension:

flatpak install --user flathub org.freedesktop.Platform.VulkanLayer.lsfgvk//25.08
